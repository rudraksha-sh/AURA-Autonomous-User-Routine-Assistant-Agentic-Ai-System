## Workflow evidence

- **Communication:** StateGraph uses a typed dictionary with an append-only trace reducer. Supervisor routes plan or simulation. Plan flows through Context, Planner, optional Replanning, Scheduler and review; approval reaches Execution and Verification. Memory and Intelligence are direct scheduler-path calls. Nodes serialize public results into state; account scope comes from authentication.
- **Checks and persistence:** Manual review interrupts with a scoped payload. A restricted, server-generated LangGraph journal is stored in the workflow row and replayed by run ID on a later request. Pausing updates the durable status and revision; resuming reopens review. Termination clears the journal. Revision compare-and-swap, input fingerprinting and ownership filters protect mutations. Grant consumption, task staging, verification and completion share one transaction. Tests demonstrate cross-request resume, duplicate start, stale revision, cancellation, tenant denial and rollback. Restart with a fresh process, incompatible journal recovery, and PostgreSQL races lack current-run evidence.
- **Error handling:** The API maps validation, permission, lookup and revision failures to HTTP responses. An injected verification failure returns 500 while preserving the pending approval and rolling back staged writes. PostgreSQL timeout and corrupt-journal paths have no focused test or structured recovery outcome. No live provider was called.
- **API and frontend:** Authenticated workflow list/detail/start/transition, audit, verification and undo endpoints share ownership checks; grant creation/transitions/stop are separate routes. The planner workspace calls list, start, simulation, replan, transition, undo and grant APIs, displays stored trace and receipt evidence, and provides manual refresh. The dedicated audit and verification endpoints have no workspace caller. Frontend wiring was inspected statically.

Windows SQLite regression run with a unique pytest `--basetemp`: 139 passed, 0 failed, 2 PostgreSQL-only concurrency tests skipped (20.54 seconds). No audit-blocking defect required a source change.
